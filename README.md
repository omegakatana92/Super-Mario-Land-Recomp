Super Mario Land — Recomp

A modern recompilation project for **Super Mario Land**, originally released for the Nintendo Game Boy.

## ROM Required

This project **does not include the original game ROM or copyrighted Nintendo assets**.

To play, you must provide your **own legally obtained ROM copy** of *Super Mario Land*. The recompilation uses the user's supplied ROM as the source material.

## Features

* Game Boy recompilation
* Requires the user's own ROM file
* No copyrighted ROM files are distributed with this project
* No original Nintendo game assets are included with the project
* Full-screen support
* Press **Alt + Enter** to toggle full-screen mode
* Designed for modern systems

## Controls

| Keyboard Key   | Game Boy Button  |
| -------------- | ---------------- |
| **X**          | A                |
| **Z**          | B                |
| **Enter**      | Start            |
| **Arrow Keys** | D-Pad / Movement |
